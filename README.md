# FarmWise AI

Build a premium, modern, AI-powered agriculture web application called "EcoAgri Intelligence".

The website should look like a real startup product rather than a college project. The design must be clean, beautiful, responsive, and mobile-first because most farmers will use smartphones.

Theme:

- Primary Colors: #2E7D32 (Green), #81C784 (Light Green), White, Beige, Earth Brown accents.

- Use soft gradients, rounded cards, subtle animations, glassmorphism where appropriate, modern shadows, and smooth transitions.

- Use high-quality agriculture illustrations and realistic farming imagery.

- Typography should be modern, clean, and easy to read.

- Large buttons and icons for easy use by elderly users.

The application should support multiple languages from the UI.

Include a language selector in the top navigation with:

- English

- Kannada

- Hindi

- Tamil

- Telugu

- Malayalam

The selected language should translate all UI text.

The navigation bar should contain:

- Logo

- Home

- AI Crop Grading

- Nearby Mandi

- Price Prediction

- Weather

- Dashboard

- About

- Contact

- Language Selector

- Login/Profile

Create the following pages:

1. Hero Landing Page

- Beautiful farming background

- Animated crops

- Headline:

  "Smart Farming Powered by Artificial Intelligence"

- Subtitle explaining AI crop grading and smart market recommendations.

- Two CTA buttons:

   - Start Crop Analysis

   - Explore Features

2. Feature Section

Display attractive cards for:

- AI Crop Grading

- Mandi Finder

- Price Prediction

- Weather Forecast

- Sell Recommendation

- Analytics Dashboard

Each card should include modern icons and hover animations.

3. AI Crop Grading Page

This should be the main feature.

Include:

Large upload card with:

- Capture Photo

- Upload from Gallery

The capture button should support mobile camera.

After upload show:

Image Preview

Loading Animation

Then a beautiful Result Card showing:

Crop Name

Grade (Grade 1 or Grade 2)

Confidence Percentage

Freshness Score

Quality Score

Suggested Market Price

Recommendation

The result should include colorful badges and progress bars.

4. Nearby Mandi Page

Show:

Google Map placeholder

Nearby Mandis

Distance

Current Price

Market Rating

Travel Time

Market Cards with modern UI.

5. Price Prediction Page

Display beautiful charts showing:

Today's Price

Tomorrow Prediction

7-Day Prediction

30-Day Trend

Best Selling Day

Include animated graphs and statistics cards.

6. Weather Dashboard

Show:

Temperature

Humidity

Rain Probability

Wind Speed

Weather Alerts

Beautiful weather widgets.

7. Farmer Dashboard

Show:

Recent Crop Analyses

Uploaded Images

Prediction History

Favorite Markets

Notifications

Charts

Profile Summary

8. Login & Signup

Modern authentication page.

Allow:

Phone Number

Email

Google Login button

Large touch-friendly UI.

9. About Page

Explain the purpose of EcoAgri Intelligence.

Include mission, vision, and team placeholders.

10. Contact Page

Contact form

FAQ

Support section

Footer

The footer should contain:

Quick Links

Social Icons

Emergency Agriculture Help

Government Agriculture Links

Language Switch

Copyright

Animations:

Smooth scrolling

Fade animations

Hover effects

Button ripple effects

Card elevation

Image zoom

Loading skeletons

General Requirements:

Fully responsive.

Mobile-first.

React + Tailwind CSS.

Beautiful component structure.

Use reusable components.

Dark mode support.

Accessibility support.

Do not use placeholder boxes.

Use realistic agriculture illustrations and icons.

Overall appearance should be comparable to modern startup websites from 2025–2026 rather than traditional government portals.
